###  Proyectos Destacados

*   **[Códigos de Barrio](link-al-repo):** Plataforma web de geolocalización y seguridad. Me enfoqué en diseñar una interfaz web clara e interactiva para el usuario, conectada a un bot de monitoreo en Node.js.
*   **[Ma'tli Mati](link-al-repo):** Software educativo para el aprendizaje de lenguas indígenas. El mayor reto y logro fue diseñar una experiencia didáctica y accesible desde cero.
*   **[Sistema de Reservas de Vuelo](link-al-repo):** Aplicación de escritorio. Diseñé las interfaces gráficas en Java Swing buscando la mejor experiencia para que el usuario gestione vuelos y genere sus boletos (PDF) de forma intuitiva.
*   **[StudentWallet](link-al-repo):** Aplicación de gestión financiera. Diseñada desde la estructura de datos hasta la interfaz visual para ayudar a universitarios a organizar sus gastos.
